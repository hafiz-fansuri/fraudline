API reference.

A small prediction contract. No public lifecycle mutation endpoints.

Score one transaction

POST /predict

{
  "transaction_id": "TEST-001",
  "amount": 249.00,
  "time_offset": 7200,
  "product": "W",
  "network": "visa",
  "card_type": "debit",
  "distance": 280,
  "identity_present": true
}

The response includes probability, approve/review/block decision, model version, thresholds, reason contributions and a persisted prediction ID.

POST /predict/batch accepts an object with a transactions array of 1–100 entries using this same contract.

Service endpoints

GET /health
Liveness
GET /ready
Verified model readiness; 503 when no model is loaded
GET /metrics
Prometheus request, error, latency and drift metrics
GET /api/model
Model metadata, evaluation and registry history
GET /api/monitoring
Latest scheduled monitoring report

Requests are limited to 64 KiB and 120 POSTs per client per minute in a single process. Invalid inputs return 422; excessive payloads 413; throttled requests 429. Send illustrative values only. Reason contributions use uncalibrated log-odds and are not causal explanations.
