API reference

Use authored synthetic values only. No real payment or personal information.

Score and investigate

POST /api/review accepts {"transaction": {...}, "question": "What evidence and human review steps apply?"}. It returns the scored risk and a separate investigation containing cited local playbooks, suggested human steps, provenance and the bounded tool trace. Questions never alter the probability. Guidance is illustrative, not approved bank policy; no external language model is called.

GET /api/playbooks lists the evidence corpus. Exact request schemas are in OpenAPI JSON.

Score a transaction

POST /predict accepts a transaction object. Get complete examples, including history and context, from /api/scenarios. 

{
  "transaction_id": "TEST-001",
  "amount": 75.0,
  "time_offset": 907200,
  "product": "W",
  "network": "visa",
  "card_type": "debit",
  "identity_present": true,
  "account_id": "demo-account",
  "device_type": "desktop",
  "history": [],
  "context": {"ip_country": "MY", "billing_country": "MY"}
}

The response separates calibrated probability, model_decision and final decision. It includes thresholds, model version, TreeSHAP reasons, contextual signals, computed history and a prediction ID. Context can escalate the decision without changing probability. Supplied history is illustrative; production needs a trusted source.

POST /predict/batch accepts {"transactions": [...]} with 1–100 entries. Each event accepts at most 200 history items. Benchmark C/D/M fields are whitelisted; arbitrary features and labels are rejected.

Read endpoints

  • /ready: verified model readiness
  • /health: process liveness
  • /api/model: metadata, evaluation, registry
  • /api/factors: nine-factor coverage
  • /api/scenarios: authored synthetic inputs
  • /api/monitoring: latest local scheduled report, if present
  • /api/drift: precomputed synthetic drift exercise, if present
  • /metrics: Prometheus service metrics
  • /openapi.json: complete typed request schema

Validation and limits

Invalid payloads return 422. Bodies above 256 KiB return 413. A demo per-process limit of 120 POST requests per client per minute returns 429. This is not distributed abuse protection. There are no public lifecycle mutation endpoints. Public Vercel audit storage is temporary and not a durable ledger.

Contribution values are raw log-odds associations before calibration, not percentage-point effects or causal explanations.
